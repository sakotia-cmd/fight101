## How to use these docs

When you start a new session with Claude Code:
1. Read [Architecture Overview](architecture.md) to remember file responsibilities
2. Read the most recent completed session for context on what was just built
3. Read the relevant entry in [Future Roadmap](roadmap.md) for the next session's prompt
4. Update the doc for the session you just finished with what actually shipped (real values may differ from the original plan)
