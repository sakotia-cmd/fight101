# Controls Reference

## In the city (default)

| Key | Action |
|-----|--------|
| WASD / Arrow keys | Move Jay |
| SPACE | Attack (sword swing, bow/gun shot, taser zap) |
| 1 / 2 / 3 / 4 | Switch to sword / bow / gun / taser (if owned) |
| H | Eat hamburger (heals 25 HP) |
| E | Interact (enter hideout, enter/exit vehicle) |
| R | Restart after game over |
| M | **Cheat:** sets coins to 9999 |

## In a vehicle

| Key | Action |
|-----|--------|
| WASD / Arrow keys | Drive |
| SPACE | Fire vehicle blaster |
| E | Exit vehicle |

## Inside the hideout

| Key | Action |
|-----|--------|
| WASD / Arrow keys | Move Jay around interior |
| E | Open shop (near shopkeeper) / exit hideout (near door) |
| F | Feed capybara (uses 1 hamburger) |
| T | Toggle decorate mode |

## In the shop

| Key | Action |
|-----|--------|
| W / S / Up / Down | Navigate items |
| Enter | Buy selected |
| ESC | Close shop |

## In decorate mode

| Key | Action |
|-----|--------|
| Arrow keys | Move cursor |
| 1 / 2 | Cycle through items in inventory |
| SPACE | Place selected item (or pick up a placed item under cursor) |
| E | Pick up the placed item under cursor (back into inventory) |
| T or ESC | Exit decorate mode |

## During boss intro cutscene

Player is locked. Cutscene auto-advances over 3 seconds (180 frames) then boss spawns.
